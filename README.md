# Notes from bunkerbot about TF2Autobot

This folder is not a working trading bot. It is a set of notes and copied source files. We wrote them so the TF2Autobot project can see which behaviors we borrowed from TF2Autobot version 5.18.0, and which behaviors we changed afterward.

Read [Overview](./OVERVIEW.md) first. That page lists each borrowed area in one place. After that, open the matching chapter in the `docs/` folder. The `src/` folder holds the bunkerbot source those chapters describe.
